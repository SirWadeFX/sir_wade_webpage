Frequently asked questions

I’ve never used Unreal Engine before. Can I take this class?

Yes. A free Intro to Unreal Engine 5.8 video series covers the fundamentals before you start, so you won’t be left behind.

I already know Unreal. What new info will be covered?

Class 01 has a heavy focus on the new 5.8 animation features, and Class 02 covers cinematic workflows and real-time production. Even if you’ve taken an Unreal class with Sir before, there’s a lot that’s new in every version.

Does this class cover worldbuilding, gamedev, etc?

Class 02 covers real-time cinematics: Sequencer, cameras, MetaHuman facial animation, mocap, lighting and rendering. It doesn’t cover worldbuilding or gameplay.

I work at a studio or a school. Are there additional training opportunities like this one?

Yes. Bulk pricing is available for studios and schools. Use the Contact for bulk pricing button above.
